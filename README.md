# Legal Case OS（法律办案 SOP 公共版）

这是一套配合 AI 使用的办案步骤和工具，供律师整理案件材料、梳理争议、记录进度和起草文书。你说明这次要做什么，提供允许使用的材料，并明确说“调用法律套件”，AI 再按相应步骤协助处理。

使用它需要 AI 软件能够读取本地技能，并在相关功能需要时运行本地程序；安装方法见下文。生成的分析和文书仍需律师核对。

## 它能帮你做什么

本包提供以下流程和工具。离线测试检查的是程序流程与检查机制，不能证明真实案件中的法律结论正确；实际测试结果见下文“验证范围与已知限制”。

1. **材料接入与读取**：给出允许使用的材料文件 → 生成材料记录，用哈希值核对文件是否变化，按范围读取正文，明确报告缺页、加密或无法提取的情况。
2. **简单案件直接起草**：一句话说明案件并给出材料 → 按内置的 13 类通用文书模板（起诉状、答辩状、上诉状、代理意见、质证意见、证据目录、授权委托书等）生成可编辑的 Word 待审稿，关键缺项先问你。
3. **复杂案件分析**：指定一个重大争点 → 梳理双方可能提出的主要理由及其依据，形成详细分析、法源研究报告和内部审阅稿；未核验的法律依据不会进入正式候选版本。
4. **案件工作区与记忆**：创建案件目录后 → 案件状态、材料批次、待核对的日期和期限、待办事项，以及从材料和工作记录中整理的记忆，都保存在案件自己的 `_case-state/` 目录，多个聊天窗口通过状态版本检查避免互相覆盖。
5. **文书检查与提交包准备**：先检查待审稿，再逐项请你批准清洁处理（如处理修订记录、批注等）→ 保留原件，生成处理后的副本、复核报告，以及带书签页码的 PDF 提交包候选，供律师继续核对。

**边界**：AI 建议不等于律师决定；本工具不会自动打印、发送、上传、送达或提交任何文件。

## 安装与启用

安装方法见 [docs/INSTALL.md](./docs/INSTALL.md)。简言之：把本仓库下载或克隆到本地，让你的 AI 软件读取 `skills/` 目录，并确保本机有 Python 3.10+。

想同时安装并连接三个项目（本套件、Agent Workstyle、Law Library MCP）时，把 [INSTALL-COMBINED.md](./INSTALL-COMBINED.md) 交给你的 AI，让它按组合方法在当前环境中执行和分层核验；三个项目仍然独立维护。

安装后，对 AI 说：

> 调用法律套件，帮我处理这次任务：……

“调用法律套件”这个口令对应本包的总控技能入口 `skills/legal-case-orchestrator/SKILL.md`。安装咨询或普通法律问题不会自动启用本套件。

## 资料和模板由谁提供

- **案件材料**：由你提供，并且始终只读；处理过程生成的是派生件。
- **个人模板库**：本包默认为空，不携带任何个人模板。模板资料（原件、画像、登记表）建议放在程序目录之外的自建资料目录，登记方法见 [library/模板库/README.md](./library/模板库/README.md)；逐份校准并经律师批准后启用。
- **通用文书模板**：`shared/templates/` 内置 13 类项目原创的通用结构模板，开箱可用（不代表任何法院指定格式）。
- **知识库/数据库**：本包不自带法律数据库。如需接入，通过你自行配置的 MCP 等只读接口提供；未配置时，仅用本次提供的材料仍可完成大部分任务。

## 生成件保存在哪里

- 独立文书任务：输出保存在你指定的任务目录（`materials/`、`draft-v1/` 等），不写入仓库。
- 案件任务：保存在案件工作区的 `20-analysis/`、`30-working/`、`40-review/`、`60-filing/` 等目录；案件状态和记忆保存在 `_case-state/`。

## 什么必须由你核对

- 关键决定：证据是否采用、文书清洁项目是否批准、提交包是否进入候选，都需要你的明确批准。
- 生成稿：Word/PDF 生成后仍需逐页检查空白页、截断、版式和签章位置。
- 期限与案号：AI 抽取的日期只是候选，必须核对原文、时区和计算依据。
- 法律结论：所有分析都是辅助，责任由执业律师承担。

## 三个项目怎么配合

三个项目各有用途，可以单独使用，也可以按需要组合：

| 项目 | 能帮你做什么 |
| --- | --- |
| [Agent Workstyle](https://github.com/gosedhuiyin/agent-workstyle) | 指导 AI 推进任务、核对依据，并配合已有技能和工具。 |
| [Legal Case OS](https://github.com/gosedhuiyin/legal-case-os-public) | 提供法律办案步骤、案件记录和文书工具。 |
| [Law Library MCP](https://github.com/gosedhuiyin/law-library-mcp) | 管理、检索和阅读自己导入的资料，并通过 MCP 给 AI 使用。 |

例如，你让 AI“调用法律套件，根据我允许访问的资料分析争议问题并整理文书草稿”：法律套件提供办案步骤；连接并授权资料库后，AI 可以通过 MCP 查资料；Agent Workstyle 则指导它推进任务、核对依据和配合工具。

组合使用需要分别安装和配置，所用 AI 软件也要支持相应的技能和工具。下载三个包不会自动把它们连接起来，安装其中一个也不会自动安装其余两个。没有资料库时，仍可直接使用本次提供的材料；没有法律套件时，资料库也可以独立检索使用。完整的组合安装步骤、分层核验和记录方法集中在 [INSTALL-COMBINED.md](./INSTALL-COMBINED.md)，由你的 AI 按其实际宿主环境执行。

## 验证范围与已知限制

- 本公共版的单元测试、离线验收和冒烟检查均在本仓库内完成，结果见 [CHANGELOG.md](./CHANGELOG.md)；测试全部使用 TEST-ONLY 虚构夹具。
- 能加载 `skills/` 目录的 AI 软件均可尝试接入；哪些客户端经过实际安装验证，以 [docs/INSTALL.md](./docs/INSTALL.md) 的记录为准，未列出的视为未实测。
- 本公共版**不包含**：个人模板原件与画像、真实案件资料、法律数据库、固定手续模板（如户籍查询双表——该能力依赖你自行配置的本地扩展，本包不提供下载）、任何外部动作执行器。
