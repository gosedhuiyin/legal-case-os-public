# 个人办案风格档案 v1

本档案只记录在多个案件任务中重复出现、且律师已经明确确认的工作习惯。它不保存客户、公司、金额、案号或案件事实，不从AI未审定草稿自动学习。以后只有律师认可的最终定稿或明确反馈才能修订本档案，并记录适用文书类型。

## 1. 首次汇报

- 内部可以充分分析，但第一次向律师汇报默认短、凝练、有逻辑。
- 优先按 `1、2、3、4` 表达：材料大致内容、最主要问题、最难矛盾、建议下一步。
- “不要那么复杂”只缩短展示，不降低内部分析深度，也不隐藏已识别的重大风险。
- 先回答用户当前问题，不用附加建议、情绪性鼓励或无关延伸代替执行。

## 2. 稿件分层

- `discussion`：用于探讨案情，可以显示假设、疑点、反方攻击路径和待核事项。
- `internal_review`：用于审阅和决策，必须显示来源缺口、不利事实、潜在自认和版本风险。
- `court_candidate`：面向法院或对方的候选稿，只保留经核验、经批准且适合对外呈现的内容。

法院候选稿不得出现“建议、注意、提醒、内部备注、参考、待核验、AI认为”等对话或审稿痕迹；批注、修订、内部ID、未决占位符和未授权水印必须为零。

## 3. 旧稿、来源与论证

- 用户指定旧稿时，先学习其结构、语气、长度、标题层级和版式，再起草；旧稿只作为个人风格范例，不是法源，也不得复制旧案事实。
- 重要事实、数字、代码结论必须绑定文件及页码或行号，并区分直接记载、用户陈述和模型推断。
- 对外表达坚定但不过度断言；内部必须展示对方最可能的反驳、不利证据和程序攻击路径。
- 案例和法条必须可核验，重大不利法源必须保留并说明区别，不能只筛选支持结果。

## 4. 证据与篇幅

- 证据不是越多越好；优先提高证明力密度，明确当前提交、后续备用、内部参考、不利和保密状态。
- 支持三轨成果：简版提交候选、详细储备稿、待确认附表。三者各有版本和用途，不能互相覆盖。
- 压缩时保留已批准请求/抗辩、举证责任、证据链、不利事实处理和来源含义。

## 5. 修改与审阅

- “只修改某处”触发最小修改保护：未授权部分不得顺手改写、润色或调整结论。
- 长文书先给一页审阅控制页，至少列：文书目的与版本、输入快照、当前门禁、关键结论、阻断项、与上一版差异。
- 同时标出最值得律师人工阅读的五处；不足五处时只列真实高风险位置，不凑数。
- 最终仍需逐页视觉检查：空白页、截断、分页、表格错位、页码、签章位置和内部痕迹。

## 6. 禁止自动学习

- 不从讨论稿、模型草稿、未审定版本或第三方模板自动归纳个人风格。
- 不把某一案件的策略、事实或措辞升级为全局偏好。
- 不因用户一次要求“简单”就永久降低分析深度；不因一次要求详细就永久增加篇幅。
