# 来源与引用规则

- 关键事实必须能追溯到来源文件和具体页码。
- 法条、司法解释、法院规则和案例必须记录可核验来源和核验日期。
- 搜索摘要、二手转述或模型记忆不能单独作为正式引用依据。
- 原文引用必须与来源一致，不得扩大裁判要旨或规范含义。
- 有重大不利法源时必须记录并说明区别，不能只保存支持结果。
- 无法核验的内容保留在研究记录中，但不得进入清洁提交版本。

## 四级来源

1. `L1_verified_authority`：在权威或官方载体核验的现行法条、规则、案例全文；记录链接或载体、核验日期和有效性。
2. `L2_original_or_official`：用户提供的原始案件材料或官方原件；记录文件哈希和页码或行号。
3. `L3_user_statement`：用户陈述；可用于待核事实和工作假设，不得伪装成已入卷事实。
4. `L4_model_inference`：模型推断；必须明确标记并等待来源核对。

搜索摘要、无法打开的案例、只有标题或二手转述的结果不得升级为L1。生产案件不得引用 `verification_status=test_only` 的模拟法源。
