# 版本和失效规则

以下变化必须标记相关下游成果为 `stale`：

- 原始来源出现新版本或页码变化；
- 关键事实被确认、推翻或改为争议；
- 争点、诉讼理论或请求发生实质变化；
- 证据被加入、移除或改变提交阶段；
- 法源失效、被替换或核验结论变化；
- 律师撤销或修改既有决定。

每份成果记录其输入对象及版本。重新生成时保留旧版、差异摘要和重新批准要求，不静默覆盖。

批准也参与失效传播。对象版本、来源哈希、诉讼阶段、包清单或授权目标不匹配时，旧批准不得复用。

失效传播至少覆盖：`Source → Fact/Issue/Evidence/Authority → Artifact → PackageManifest → Approval/ExternalAction`。脚本只根据显式 `input_snapshot` 和包清单关系传播；无法证明依赖关系时应增加阻断项，不能猜测为“仍然有效”。

同名文件不代表同一版本。来源内容哈希变化时，即使路径、文件名和页数不变，也必须增加版本并让依赖旧哈希的成果失效。旧成果保留，不静默覆盖。
