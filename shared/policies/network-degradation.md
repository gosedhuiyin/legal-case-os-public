# 联网与能力降级

材料通道与本次使用/长期保存的共同规则见[材料访问与学习](material-access-and-learning.md)。知识库调阅权限和公开互联网权限分别判断，不把“不得公开联网”自动解释为禁用已授权的本地只读资料库。

## 已配置的知识库

知识库连接由当前客户端或用户配置提供，不依赖固定的开发机目录或 MCP 服务名称。仅在本次任务已有相应资料访问授权时，使用实际可发现、已认证且符合读取范围的只读 MCP 工具；读取本规则本身不产生新的资料访问授权。SOP不保存数据库管理员凭据，不修改服务、类别权限、入库开关或向量配置。启动检查和检索不触发同步、OCR或向量补齐。

已有模板和案情足够时直接读取并产出，无需先检查数据库健康。需要找资料时保留原问题，以 `find_template`、`search_library`、`search_document` 文字查询为先；必要时补充关键词组，精确案号、必含文字、范围与版本条件不放宽。文字不足时按当前任务授权使用 `search_semantic` 独立补充；语义结果不替换文字结果。

按返回入口续读完整原文，再核对观点角色和程序阶段；不能把相似分数、旧自动标签或OCR当作已核验结论。原件读取、固定版本和引用通过现有接口及[操作说明](../../docs/OPERATOR-GUIDE.md)处理；没有原版DOCX时不承诺原Word版式保真。

## 公开互联网

材料阅读默认不启动公开网页搜索。用户要求找案例、补充检索或当前已授权研究任务需要核验时，可以使用实际可用的公开检索能力，除非用户明确禁止。新的会员库、第三方付费服务或额外凭据不随既有知识库访问授权自动开放。已具备的授权不重复询问。

## 故障接续

| 状态 | 接续方式 |
|---|---|
| 外部模型/API不可用 | 保留文字检索；已有向量锚点可用 `find_related`，相同问题可用已存缓存；无缓存新问题不假装有语义结果 |
| OpenSearch不可用、PostgreSQL正常 | 接受服务明确标注的PostgreSQL文字降级；不承诺相同排名 |
| MCP或数据库不可用 | 用本次已固定且仍有使用权限的材料、明确授权本地文件或上传文件继续同一任务；不绕开权限直连残留索引 |
| 所有历史资料后端不可用 | 仅依据当前上传模板、案例和案情继续分析、提炼、起草；覆盖限于实际可读材料 |
| 无权限或明确撤销访问 | 不通过旧缓存绕过；只有另有独立本次授权的本地/上传来源才能按该来源使用 |
| 版本变化 | 重新取得当前来源或明确使用已授权历史快照，标记影响；不自动覆盖已有文书 |
| 语义超时 | 不自动重复提交可能仍在后台计费的请求，继续可用文字/文件步骤 |

`find_related` 的离线只表示不访问外部模型，仍依赖本地数据库。空结果、权限拒绝、版本失效和服务不可用必须分开记录。缺乏关键现行法源时继续可完成的内部分析与初稿，将受影响命题列为待核；不得冒称正式引用已核验。

检索停止于当前争点得到足够来源与重大反方核对、继续只产生重复、授权范围已读完，或实际访问/核验受阻。记录已用来源、遗漏范围和具体限制，不用固定轮数、模型记忆或搜索片段假装完成。
