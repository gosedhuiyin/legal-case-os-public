# 模板库使用边界

`template-registry.json` 是模板注册表；`forms/*.md.tmpl` 是从零编写、可审计的文本结构。每项登记来源、许可、版本、哈希、固定字段、可编辑字段、必填字段和别名。

使用模板前必须同时满足：注册状态为 `active`、许可状态为 `verified`、文件哈希与登记一致、全部必填字段非空。别名不存在或不唯一时必须停止，不得宣称已经套用用户所指模板。

这些文件不内置法条、法院特定份数、电子送达规则或签章要求。程序性字段应在具体案件中依据当前规则核验。`.md.tmpl` 可生成 Markdown、文本或真实 OOXML DOCX；本机存在 LibreOffice 时可在短ASCII临时目录转换为真实 PDF，并校验文件签名与页数。后端缺失或转换失败时必须明确降级并拒绝输出，禁止用改扩展名方式制造伪文件。DOCX/PDF生成后仍需逐页视觉复核，不能因转换成功自动升级为法院提交稿。
