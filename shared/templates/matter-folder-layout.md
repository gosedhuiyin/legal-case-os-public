# 单个案件目录模板

```text
案件目录/
|-- 00-originals/       原始材料，只读
|-- 10-index/           材料清单、OCR和页码索引
|-- 20-analysis/        事实、时间线、争点和研究
|-- 30-working/         提纲和工作稿
|-- 40-review/          带来源标记的审阅稿和差异报告
|-- 50-approved/        律师批准的文书和证据决定
|-- 60-filing/          待提交及已提交包、清单和回执
`-- _case-state/        结构化案件状态和版本记录
```

原始材料不得被覆盖。提交包候选必须从 `50-approved` 的当前G2证据和审阅通过、非失效文书生成，并保留清单及输入快照；G4批准精确包快照后，G5才可授权具体外部动作。

`_case-state/case-state.json` 是唯一当前状态源；`audit-log.jsonl` 只追加事件。`10-index` 中的清单是派生视图，必须带状态哈希，不能反向覆盖状态。

“整理文件夹”应新建候选目录并复制或生成所需派生件，不移动、删除或改名 `00-originals` 中的文件。`60-filing` 只是候选和历史包目录；本项目不执行实际发送、上传或提交。
