# Complex Composition

Apply this to coordinated multiple-input work. A single reference template and straightforward current facts need only compact task source/field records. An internal complex draft may use a task-local source/argument map without complete case-state; production court-candidate composition commands still require their validated state-bound CompositionSpec. Audience/gates follow [execution recipes](../../../shared/policies/execution-recipes.md) and [human approval](../../../shared/policies/human-approval.md).

## Profile selection

If the user names one eligible template, use it as the primary template. If the user names several or none, select and record:

- one layout primary;
- one structure/tone primary, which may be the same template;
- no more than three section-specific auxiliaries, each limited to named sections and functions.

Do not give every exemplar equal weight. If conflicting profiles could change relief, position, evidence use, controlling authority, or outward-facing risk, ask one consolidated question. Resolve ordinary style differences by the declared primary roles and record the choice.

## CompositionSpec

Freeze the document goal and audience before loading substantive inputs. Build the specification in this order:

1. resolve exact template/profile versions and hashes;
2. identify dangerous issues and bind any required deep-analysis result;
3. obtain and compare supporting/adverse sources; formal legal propositions need verified authority and ClaimBindings, while unresolved internal argument candidates remain explicitly conditional;
4. map current source-supported facts and evidence to sections; distinguish proposed internal use from current-stage approved submission;
5. declare template roles, reusable aspects, forbidden transfers, output constraints, and review validators;
6. validate the task's source/argument map; run `composition-validate` when using the formal state-bound composition workflow before claiming it ready.

Apply this precedence:

`current verified matter facts/evidence/authority > G1/G2 lawyer decisions > current procedural format requirements > primary template > auxiliary exemplars > global personal style`

A `CompositionSpec` is an internal control artifact. It must not be embedded in the outward document. Drafting uses it to create a new candidate; `citation-audit` and `exemplar-leak-check` must pass before independent review can approve a court candidate.

## Failure and degradation

An inaccessible source, unverifiable case text, search snippet, stale binding or unresolved high-risk conflict blocks the affected formal proposition. Continue the supported internal analysis and draft using permitted uploads/local sources, stating the limit. Do not substitute model memory, an unqueried database claim or old-template law. Attributed prior opinions may be compared with their premises and limits; they are not current-case facts or verified authority merely because they appear in a template. No composition step authorizes printing, sending, uploading, service, or filing.
