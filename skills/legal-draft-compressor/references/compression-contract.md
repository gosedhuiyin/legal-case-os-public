# Compression Contract

## Inputs

- source artifact ID, version, hash, audience, and input snapshot;
- explicit word/page/section target or reduction percentage;
- protected claims, defenses, propositions, quotations, evidence chains, and ranges;
- current strategy and evidence approvals;
- allowed modification scope.

## Outputs

- new compressed artifact and hash;
- before/after word and rendered-page counts;
- deleted, merged, and rewritten item list with locations;
- protected items and source mappings preserved;
- any change with possible substantive effect;
- safest achieved length and why a more aggressive target was refused;
- `review_status=needs_review`.

Compression must not:

- introduce facts, authorities, evidence, admissions, concessions, or new requests;
- change burden, proof strength, chronology, adverse-fact treatment, or source meaning;
- remove an unresolved warning only to make a court draft look cleaner;
- make changes outside a user-imposed local edit scope.

Run visual page comparison when the target is page-based. A lower word count does not prove a page-layout target was met.
