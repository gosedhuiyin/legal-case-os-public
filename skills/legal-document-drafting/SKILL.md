# Legal Document Drafting

Follow [material access and learning](../../shared/policies/material-access-and-learning.md) and [execution recipes](../../shared/policies/execution-recipes.md). Freeze document type, exact selected inputs, permitted change scope and audience using available context. Ordinary “生成文书” means an editable `internal_review` draft unless the user requests another audience. Do not ask for a complete case-state, permanent template registration or G1/G2/G4 just to draft it.

A simple task with a selected template and sufficient facts goes directly through key-field/risk review, drafting, source/residue checks and necessary layout review. Keep missing ordinary fields blank or explicit in an internal gap list. Clarify only a material uncertainty in relief, important amounts, authority, position or conflicting facts; complete unaffected sections while that issue remains unresolved.

Use exact source file/hash records. An uploaded template is immediately eligible for the user's specified current use. Existing approved profiles remain useful when version/hash match; one reference template does not require a full CompositionSpec. Multi-input complex work adds bounded issue analysis, supporting/adverse comparison and coordinated source bindings; formal production composition commands retain their validated CompositionSpec requirements.

Apply source-based style, observable methods and attributed conditional opinions from selected examples. Re-establish current facts and premises; never transplant prior-party names, amounts, evidence or conclusions as current-case truth. A factual number needs a source or visible assumption; an unverified legal proposition remains a task hypothesis or research lead rather than a verified formal citation.

## Audience

- `discussion`: alternatives and uncertainty; no file changes unless requested.
- `internal_review`: useful editable draft; preserve source gaps and risks in an accompanying review record. Do not label strategy, evidence or submission as approved.
- `court_candidate`: apply [human approval](../../shared/policies/human-approval.md), current G1 and applicable G2, source/authority verification, independent review and clean outward prose. G4 is reserved for an exact package.
- Client communication: freeze recipient/purpose, keep `internal_review`, review confidentiality and outgoing meaning, and deliver an unsent draft.

For format-sensitive forms, use real DOCX structure and the applicable field/fidelity checks from the curator. For writing references available only as extracted text, generate a new editable document without claiming original Word layout preservation. An unsupported mechanical template command may require another authorized generation method; never claim it ran successfully.

Use [the local CLI](../../scripts/legal_case_os.py) and [operator guide](../../docs/OPERATOR-GUIDE.md) for available material import/read, task rendering, profile/fill, citation and leakage checks. File generation proves only the produced artifact; the AI still performs substantive drafting and review. Keep source ledgers, learning/profile data, confirmations and internal risks outside outward-facing prose.

For “只改××”, bind the exact version and region, create a derived artifact, and use the applicable structural or `min-diff` check to preserve other content. Never overwrite the source.

Read [drafting contract](references/drafting-contract.md) for output-specific prerequisites and [template and artifact rules](references/template-and-artifact.md) for source resolution, file format and narrow edits.
